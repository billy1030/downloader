# Plan 02-02: Progress Streaming & OS File Reveal

## Goal
Connect real-time progress callbacks from the download engine to the queue event listener, throttle updates, and provide cross-platform OS file reveal integration.

## Requirements Covered
- QMAN-02: Real-time progress metrics (percent, speed, ETA, total size)
- QMAN-04: Open completed file or reveal in Finder / File Explorer

## Tasks
1. Implement progress bridge with throttling (`pkg/queue/progress.go`): captures `DownloadProgress` from `pkg/engine` and publishes to queue subscribers.
2. Implement OS file explorer reveal (`pkg/queue/reveal.go`): opens Finder on macOS (`open -R`), Explorer on Windows, or xdg-open on Linux.
3. Add CLI/test verification demonstrating multiple simultaneous downloads with live status reporting.

## Verification
- `go test ./pkg/queue -v` all pass.
- Verification script runs multiple concurrent tasks and asserts completion and progress notifications.
