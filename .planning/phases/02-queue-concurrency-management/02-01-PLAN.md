# Plan 02-01: Concurrency Queue & Task State Machine

## Goal
Implement a robust in-memory task queue and concurrency worker pool in Go that manages download job lifecycles with thread safety, pause/resume, and cancellation.

## Requirements Covered
- QMAN-01: Multiple downloads queue with configurable concurrency limit
- QMAN-03: Pause, resume, cancel, and remove jobs from queue

## Tasks
1. Define queue data models (`pkg/queue/types.go`): `Task`, `TaskStatus`, `QueueStats`.
2. Implement worker pool manager (`pkg/queue/manager.go`): semaphore-limited goroutine worker dispatch, thread-safe task store (`sync.RWMutex`), task enqueueing.
3. Implement task controls: cancel using `context.CancelFunc`, pause/resume states, and task deletion.
4. Write unit tests testing concurrent enqueueing, worker limits (e.g. max 2 active), and cancellation.

- `go test ./pkg/queue -v -run TestQueueCancel` passes.
