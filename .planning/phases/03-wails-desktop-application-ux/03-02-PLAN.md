# Plan 03-02: Desktop Dashboard UI & Wails Project Configuration

## Goal
Build the desktop frontend (React + Tailwind CSS + Lucide icons), Wails configuration files (`wails.json`, `main.go`), quality selection modal, active queue cards, and settings drawer.

## Requirements Covered
- DESK-01: Standalone desktop window interface built with Go and Wails v2 with polished dark mode theme

## Tasks
1. Create `wails.json` and `main.go` desktop entrypoint.
2. Build modern frontend application (`frontend/`):
   - Hero URL input bar with paste button and format quick-selector.
   - Clipboard auto-detect banner/popup ("Download detected TikTok/YouTube link?").
   - Active download cards with real-time animated progress bars, speed badges, ETA counters, and cancel/reveal actions.
   - Quality inspection modal allowing selection of resolution (4K, 1080p, 720p) or MP3 audio extraction.
   - Settings drawer for output folder selection, concurrency slider, and engine updater button.
3. Verify production compilation and asset bundling.

## Verification
- Frontend builds cleanly via Vite/Node or bundled assets.
- `go build` compiles standalone desktop application executable.
