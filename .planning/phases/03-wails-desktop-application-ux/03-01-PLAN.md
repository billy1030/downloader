# Plan 03-01: Wails Bridge, Clipboard Monitor & Engine Updater

## Goal
Implement the Go application service layer (`App`), clipboard watcher, settings store, and yt-dlp auto-updater ready for Wails desktop binding.

## Requirements Covered
- DESK-02: Clipboard auto-detection for supported media URLs
- DESK-03: Settings management (download dir, concurrency, proxy)
- DESK-04: In-app one-click check and update for yt-dlp engine

## Tasks
1. Implement `pkg/config/settings.go`: load/save user preferences (`downloads_dir`, `concurrency`, `proxy`, `clipboard_auto_detect`).
2. Implement clipboard watcher (`pkg/clipboard/watcher.go`): detects when a supported media link is copied and triggers callback.
3. Implement updater (`pkg/engine/updater.go`): runs `yt-dlp -U` or checks version.
4. Implement `app.go`: Wails lifecycle coordinator exposing `InspectURL`, `EnqueueDownload`, `GetTasks`, `CancelTask`, `RemoveTask`, `UpdateSettings`, `CheckUpdateEngine`.

## Verification
- Unit tests verify settings persistence and updater parsing.
