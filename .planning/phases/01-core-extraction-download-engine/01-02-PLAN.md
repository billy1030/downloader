# Plan 01-02: Media Downloader & Format Muxer

## Goal
Implement the download execution runner that builds format specifiers (resolution targeting, audio extraction), executes `yt-dlp` with `ffmpeg` muxing, streams progress, and handles process cancellation cleanly.

## Requirements Covered
- FMT-01: Video resolution selection (4K, 1080p, 720p, etc.)
- FMT-02: Audio-only extraction (MP3, M4A) with bitrate control
- FMT-03: Automatic video/audio stream muxing via ffmpeg

## Tasks
1. Implement format argument builder (`pkg/engine/formats.go`): constructs `yt-dlp` format string based on user requested resolution or audio conversion flags.
2. Implement downloader runner (`pkg/engine/downloader.go`): executes download process via `exec.CommandContext`, parses stdout `--progress-template` in real-time, and fires progress callbacks (`Percent`, `Speed`, `ETA`, `TotalSize`).
3. Implement process isolation & graceful cancellation (`pkg/engine/process.go`): manages process group IDs (`syscall.Setpgid`) to cleanly kill yt-dlp and child ffmpeg processes on context cancellation.
4. Add end-to-end integration tests for video download, audio extraction, and cancellation.

## Verification
- `go test ./pkg/engine -run TestDownload -v` passes.
- Verification script runs a short media clip download, asserts correct output file creation and metadata tags.
