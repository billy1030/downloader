# Plan 01-01: Engine Foundation & Metadata Inspector

## Goal
Build the Go engine package with binary environment detection (`yt-dlp` and `ffmpeg`), URL validation for supported platforms (YouTube, TikTok, Douyin, Instagram, X, Facebook), and structured JSON metadata extraction.

## Requirements Covered
- PLAT-01: YouTube metadata extraction
- PLAT-02: TikTok media extraction
- PLAT-03: Douyin media extraction
- PLAT-04: Instagram media extraction
- PLAT-05: X (Twitter) media extraction
- PLAT-06: Facebook media extraction

## Tasks
1. Initialize Go module `omnidrop` with project structure (`pkg/engine`, `pkg/models`).
2. Implement binary detector (`pkg/engine/detector.go`): detects `yt-dlp` and `ffmpeg` in system PATH or local application directory.
3. Implement URL parser and platform matcher (`pkg/engine/platform.go`): recognizes YouTube, TikTok, Douyin (`douyin.com`, `iesdouyin.com`, `v.douyin.com`), Instagram, X/Twitter, and Facebook URLs.
4. Implement metadata inspector (`pkg/engine/inspector.go`): runs `yt-dlp --dump-single-json` and decodes into clean Go structs (`MediaInfo`, `FormatOption`).
5. Write unit and integration tests verifying platform parsing and mock/live metadata extraction.

## Verification
- `go test ./pkg/engine -v` passes.
- CLI smoke test extracting metadata from a sample public URL returns valid JSON.
